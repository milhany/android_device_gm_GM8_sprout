## Status-bar Fragment lifecycle

At 16:35:20, com.android.systemui crashes in
StatusBarIconController.getIconHideList called by
CollapsedStatusBarFragment.onTuningChanged with a null Fragment context.
The SDK 32 source registers a TunerService listener in onViewCreated but does
not remove it in onDestroyView. Remove the listener when the view is destroyed,
and ignore queued callbacks when the view or context is unavailable. Live and
recreated views retain clock blacklist behavior.

## Optional Lineage charging control

HealthInterfaceService cannot start because ChargingControlController probes
getSupportedMode through a null optional IChargingControl HAL. The constructor
already recognizes the missing HAL and isSupported already returns false, but
mode probes happen before that capability check. Return false for those probes
when the HAL is absent. Keep existing capability bits and RemoteException
behavior when a HAL is present. This fixes optional-service initialization; it
does not implement charging limits or alter the stock charger, thermal control,
or Android hardware.health battery reporting.

## Apply, build and sign

The framework repairs live as patches in this device repository, not in
the vendor GPU branch. The apply helper validates all source trees before
editing any, preserves unrelated local work, recognizes previously applied
patches and refuses mismatched source. Preflight checks their application and
the build helper applies them automatically. Build records now capture
frameworks/base, lineage-sdk and packages/apps/Trebuchet revisions and local diffs.

```sh
cd ~/android/lineage-19.1
python3 device/gm/GM8_sprout/tools/apply-runtime-compat.py
python3 device/gm/GM8_sprout/tools/tests/runtime_19_1_test.py --top .
bash device/gm/GM8_sprout/tools/build-19.1.sh target-files user
```

Use release-19.1.py prepare/sign on the resulting target-files with the existing
../gm8-signing/keys and a fresh output directory. See [RELEASE-19.1.md](RELEASE-19.1.md).
Target-files are not the installable OTA. An already installed release build
must retain the same signing keys; this change does not require a new key set.
